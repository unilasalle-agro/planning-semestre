Gantt de semestre

Déposez le planning du semestre (Excel ou CSV). Le Gantt regroupe les modules selon les colonnes de votre choix (le champ « groupe » par défaut) et fait ressortir les examens et les remises de rapports. Le fichier reste dans votre navigateur et n’est envoyé nulle part.

Déposer un fichier .xlsx ou .csv ici, ou cliquer pour le choisir Colonnes obligatoires : Date et Module. Les autres colonnes (UE, groupe, type d’activité…) peuvent servir au regroupement.
Exporter ▾

Chaque colonne est un jour, chaque trait un jour de cours. Survolez un jour pour voir les horaires. « Créneaux » compte les lignes du fichier, groupes parallèles inclus. Les chiffres sous l’axe des mois sont les lundis.

Ajouter une remise de rapport

Les remises ajoutées ici sont mémorisées dans ce navigateur, sur cet ordinateur. Pour les conserver ou les partager, téléchargez le planning mis à jour : elles y figurent sur des lignes de type REMISE, que l’application relit au prochain dépôt.

Ajouter une période bloquée

La période s’applique à tous les modules et s’affiche en bande verticale sur tout le Gantt. Les dates de début et de fin sont incluses. Elle est mémorisée dans ce navigateur, sur cet ordinateur seulement ; elle n’est pas ajoutée au fichier .xlsx exporté.

Types d’activité comptés comme examens

Par défaut, tout type qui commence par « EXAMEN ». Cochez d’autres types (DS, partiel…) si besoin. Les lignes de type REMISE ou RAPPORT sont toujours lues comme des remises.
